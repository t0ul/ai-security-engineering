# the attack

No input file; the attack is a URL the tool is told to fetch. A hostile email got
the model to aim the agent's web-search tool not at the web but at the agent's own
machine: a loopback address and the cloud-metadata address. A tool that fetches
whatever URL it is handed will reach both. The internal server here is a throwaway
local listener standing in for something that should never be reachable.
