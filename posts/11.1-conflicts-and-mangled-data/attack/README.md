# the attack

No input file, and no attacker. The adversary this chapter faces is wrong data:
school emails that contradict themselves and models that pass the contradictions
through. Four classes stand in for the rest.

- weekday: an event dated "Thursday, September 29th" when the 29th is a Tuesday.
- borrowed time: an event with no time in its own text handed a fabricated one.
- negation inversion: "we do not accept late forms" cleaned into "accept late
  forms", flipping the meaning.
- duplicate / conflict: the same event announced on two different dates.

The question is whether the agent trusts an extracted record or re-checks it with
deterministic code that cannot be talked into agreeing.
